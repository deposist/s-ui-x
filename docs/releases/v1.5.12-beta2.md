# Release Notes: v1.5.12-beta2
Release date: 2026-08-13

v1.5.12-beta2 is the second beta of the 1.5.12 line. The embedded core is updated to sing-box v1.13.18, three dependency advisories are fixed, and x-ui import stops with a clear error when the source database cannot be opened. No manual migration is required.

## Core update

The panel now embeds sing-box v1.13.18 with sing v0.8.13 and wireguard-go v0.0.4. These are patch releases from the upstream line.

## Security fixes

Three Go dependency advisories are fixed:

- quic-go v0.59.1: HTTP/3 QPACK memory exhaustion (GO-2026-5676)
- golang.org/x/text v0.39.0: infinite loop on invalid internationalized-domain input (GO-2026-5970)
- google.golang.org/grpc v1.82.1: HTTP/2 transport and xDS RBAC vulnerabilities (GO-2026-6061)

Frontend packages are updated as well: axios 1.19.0 and transitive fixes for postcss, nanoid, brace-expansion, and immutable. `npm audit` reports zero vulnerabilities.

## x-ui import

When the source database cannot be opened, import stops with a clear error instead of continuing without a working connection.

Устранили три уязвимости в Go-зависимостях:

- quic-go v0.59.1: исчерпание памяти при HTTP/3 QPACK (GO-2026-5676)

Обновили и frontend-пакеты: axios 1.19.0, а также транзитивные исправления postcss, nanoid, brace-expansion, immutable. `npm audit` уязвимостей не находит.

# 更新日志: v1.5.12-beta2
发布日期: 2026-08-13

v1.5.12-beta2 是 1.5.12 分支的第二个 beta。内置内核更新到 sing-box v1.13.18，修复三个 Go 依赖中的安全公告，并且当源数据库无法打开时 x-ui 导入会明确报错。无需手动迁移。

## 内核更新

面板现在嵌入 sing-box v1.13.18、sing v0.8.13 和 wireguard-go v0.0.4。这些是上游分支的补丁版本。

## 安全修复

修复三个 Go 依赖中的安全公告：

- quic-go v0.59.1: HTTP/3 QPACK 内存耗尽 (GO-2026-5676)
- golang.org/x/text v0.39.0: 无效国际化域名输入导致死循环 (GO-2026-5970)
- google.golang.org/grpc v1.82.1: HTTP/2 传输和 xDS RBAC 漏洞 (GO-2026-6061)

前端依赖也已更新：axios 1.19.0 以及 postcss、nanoid、brace-expansion、immutable 的传递修复。`npm audit` 报告 0 个漏洞。

## x-ui 导入

当源数据库无法打开时，导入会停止并显示明确错误，而不是在没有有效连接的情况下继续。

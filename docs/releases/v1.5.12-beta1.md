# Release Notes: v1.5.12-beta1
Release date: 2026-08-01

v1.5.12-beta1 is the first beta of the 1.5.12 line. It finishes the ext-to-upstream port: the panel now runs only on official sing-box v1.13.15 with a strict capability contract, hardened self-update, paid subscriptions, and full frontend parity. No manual migration is required.

## Official core and capabilities

The panel builds only against official `github.com/sagernet/sing-box v1.13.15`. All fork patches, extended protocol tags, and third-party build flags were removed.

A capability manifest (`core/capabilities/protocols.json`) drives every layer. Backend validation, frontend editors, import, doctor diagnostics, and runtime checks all reject unsupported types before persistence. Historical rows stay inspectable and editable only when the type matches the running build.

## Self-update safety

The updater is now a single binary-and-database transaction. Before any file is replaced, the panel writes a JSON transaction marker with SHA-256 digests of the candidate, backup, and a `VACUUM INTO` database snapshot. Recovery runs before migrations and fails closed on malformed state or identity mismatch. A healthy start confirms the transaction and deletes rollback artifacts; a failed start rolls back both binary and database.

A state-leak in the update flow was found and fixed during final audit: an `os.Stat` error on the pending marker could leave the service permanently blocked. All error paths now reset the update state before returning.

## Paid subscriptions

Payment orders persist immutable grant days, traffic, and snapshot version. Creation snapshots the tariff; settlement and refund read only the order snapshot. Legacy orders without a snapshot enter permanent manual review with preserved provider evidence.

CryptoBot invoice identity is first-class. Creation is serialized and fail-closed. Reconciliation runs before bounded polling and terminal expiry, prefers paid duplicates, cancels active siblings, and persists failed cancellation retries across restarts.

Backup and restore now include bindings, tariffs, orders, poll cursors, and cancellation retries.

## Frontend and UX

Classic and Nexus share menu metadata and a palette-aware theme. Async modal operations use cancellation plus generation fences. Overview traffic supports timezone selection with persistence and offset labels.

Entity drawers and Classic editors reject blank identities, invalid ports, missing TLS, and unavailable runtime capabilities with visible localized reasons. Protocol guidance is capability-gated and display-only; unreachable apply controls were removed.

All six shipped locales (`en`, `ru`, `fa`, `vi`, `zhcn`, `zhtw`) now expose the same leaf-key structure. Missing translations fall back to English at runtime but are materialized in the bundle so tests reject structural drift.

## Security and reliability

Session regeneration, SQLite sessions, CSRF, WebSocket origins, rate limits, cookie invariants, and backup confidentiality are covered by focused race tests. Token mutations are owner-scoped and reload the live cache. Reset-required users receive only reset/CSRF/logout access until a durable password change.

IP admission handles cold cache misses synchronously with revision-qualified singleflight and fencing against stale refreshes. WebSocket token-fetch failure enters degraded polling and recovers without parallel reconnect loops.

## Verification

Sequential backend verification passed: `go build ./...`, `go vet ./...`, `go test ./...` (24 packages), and `go test -race -timeout=20m ./...`. Frontend verification passed: 41 test files, 239 tests, lint, production build, and 126 verified dist assets. Full Playwright smoke passed with 30 tests and 3 explicit skips.

# Заметки о релизе v1.5.12-beta1
Дата релиза: 2026-08-01

v1.5.12-beta1 - первая бета-версия ветки 1.5.12. Она завершает перенос с расширенного ядра: панель работает на официальном sing-box v1.13.15, проверяет возможности ядра, безопасно обновляет себя и поддерживает платные подписки. Ручная миграция не нужна.

## Официальное ядро и проверка возможностей

Панель собирается только с официальным `github.com/sagernet/sing-box v1.13.15`. Патчи форка, дополнительные протоколы и сторонние флаги сборки удалены.

Манифест `core/capabilities/protocols.json` используется во всех слоях приложения. Серверная проверка, редакторы, импорт, диагностика и проверки при запуске отклоняют неподдерживаемые типы до записи в базу. Исторические записи можно просматривать и редактировать, если их тип поддерживает текущая сборка.

## Безопасное самообновление

Самообновление стало общей транзакцией для исполняемого файла и базы данных. До замены файлов панель записывает JSON-маркер с SHA-256 для нового файла, резервной копии и снимка базы, созданного через `VACUUM INTO`. Восстановление выполняется до миграций. Ошибка формата или несовпадение контрольной суммы останавливает запуск. После успешного запуска панель подтверждает транзакцию и удаляет файлы отката. Если запуск не удался, восстанавливаются исполняемый файл и база.

Финальная проверка выявила утечку состояния обновления. Ошибка `os.Stat` при чтении маркера могла навсегда заблокировать новые обновления. Код теперь очищает состояние перед каждым возвратом с ошибкой.

## Платные подписки

Заказы сохраняют срок, объём трафика и версию снимка тарифа. При создании заказа тариф копируется в заказ, поэтому оплата и возврат не зависят от последующих изменений тарифа. Старые заказы без снимка переводятся на ручную проверку, а ответ платёжного провайдера сохраняется.

Идентификатор счёта CryptoBot хранится отдельно. Создание счетов выполняется последовательно и останавливается при ошибке. Сверка проходит до ограниченного опроса и истечения срока, выбирает оплаченный дубликат, отменяет остальные активные счета и сохраняет неудачные попытки отмены после перезапуска.

Резервное копирование и восстановление охватывают привязки, тарифы, заказы, позиции опроса и повторные попытки отмены.

## Интерфейс

Classic и Nexus используют общее меню и тему с учётом палитры. Незавершённые операции в модальных окнах отменяются, а устаревшие ответы не меняют текущее состояние. На главной странице можно выбрать часовой пояс для графика трафика; выбор сохраняется и показывает смещение.

Формы не принимают пустые идентификаторы, неверные порты, отсутствующий TLS и функции, которых нет в текущем ядре. Причина ошибки показывается на выбранном языке. Подсказки по протоколам зависят от возможностей ядра и доступны только для чтения; недоступные кнопки применения удалены.

Все шесть локалей (`en`, `ru`, `fa`, `vi`, `zhcn`, `zhtw`) имеют одинаковый набор ключей. Для непереведённых строк используется английский текст, а тесты проверяют структуру каждого языкового пакета.

## Безопасность и надёжность

Гонка данных проверена в сценариях с обновлением сессий, сессиями SQLite, CSRF, WebSocket Origin, ограничением запросов, параметрами cookie и защищёнными резервными копиями. Изменение токенов ограничено владельцем и перезагружает рабочий кеш. Пользователь с обязательной сменой пароля имеет доступ только к смене пароля, CSRF и выходу, пока новый пароль не сохранён.

При пустом кеше проверка IP выполняется синхронно. Одинаковые запросы объединяются, а устаревшее обновление не может перезаписать свежие данные. Если WebSocket не получает токен, интерфейс переходит на обычный опрос и возвращается к WebSocket без параллельных циклов переподключения.

# 更新日志: v1.5.12-beta1
发布日期: 2026-08-01

v1.5.12-beta1 是 1.5.12 分支的第一个 beta。此版本完成 ext-to-upstream 迁移：面板仅基于官方 sing-box v1.13.15 构建，具备严格的 capability 合约、加固的 self-update、付费订阅和完整的 frontend 一致性。无需手动迁移。

## 官方内核与 capabilities

面板现在仅使用官方 `github.com/sagernet/sing-box v1.13.15` 构建。所有 fork 补丁、扩展协议标签和第三方构建标志均已移除。

Capability 清单 (`core/capabilities/protocols.json`) 驱动所有层。后端验证、前端编辑器、导入、doctor 诊断和运行时检查都会在持久化之前拒绝不支持的类型。历史行保持可检查和可编辑，但仅当类型与当前构建匹配时才允许。

## Self-update 安全性

更新器现在是一个二进制加数据库的单一事务。替换任何文件之前，面板会写入一个 JSON 事务标记，其中包含候选文件、备份和 `VACUUM INTO` 数据库快照的 SHA-256 摘要。恢复在迁移之前运行，并在状态格式错误或身份不匹配时 fail closed。成功启动会确认事务并删除回滚工件；启动失败会回滚二进制文件和数据库。

最终审计中发现并修复了更新流程中的状态泄漏：pending marker 的 `os.Stat` 错误可能导致服务永久阻塞。现在所有错误路径都会在返回前重置更新状态。

## 付费订阅

支付订单保存不可变的授权天数、流量和快照版本。创建时会快照资费；结算和退款仅读取订单快照。没有快照的旧订单会进入永久人工审核状态，并保留提供商证据。

CryptoBot 发票身份成为一等公民。创建过程是串行且 fail-closed 的。对账在有界轮询和终端过期之前运行，优先处理已支付的重复项，取消活动同级项，并在重启之间保留失败的取消重试。

备份和恢复现在包括绑定、资费、订单、轮询游标和取消重试。

## 前端和 UX

Classic 和 Nexus 共享菜单元数据和调色板感知主题。异步模态操作使用取消加生代栅栏。概览流量支持带持久化和偏移标签的时区选择。

实体抽屉和 Classic 编辑器拒绝空白标识、无效端口、缺失 TLS 和不可用的运行时能力，并显示可见的本地化原因。协议指导是 capability 门控且仅显示的；不可达的 apply 控件已移除。

所有六种发布语言 (`en`, `ru`, `fa`, `vi`, `zhcn`, `zhtw`) 现在暴露相同的叶键结构。缺失的翻译在运行时回退到英语，但会在包中具体化，因此测试会拒绝结构漂移。

## 安全性和可靠性

会话重新生成、SQLite 会话、CSRF、WebSocket 源、速率限制、cookie 不变量和备份机密性由重点竞态测试覆盖。令牌变更是所有者范围的并重新加载实时缓存。需要重置密码的用户在持久密码更改之前只能获得 reset/CSRF/logout 访问权限。

IP 准入使用修订限定的 singleflight 同步处理冷缓存未命中，并对过期刷新进行防护。WebSocket 令牌获取失败进入降级轮询并恢复，不会产生并行重连循环。

## 验证

顺序后端验证通过: `go build ./...`, `go vet ./...`, `go test ./...` (24 个包) 和 `go test -race -timeout=20m ./...`。前端验证通过: 41 个测试文件, 239 个测试, lint, 生产构建和 126 个验证的 dist 资源。完整的 Playwright 冒烟测试通过，30 个测试通过，3 个显式跳过。

# Release Notes: v1.5.9-beta2

Release date: 2026-06-16
**EN**

v1.5.9-beta2 is a small follow-up to v1.5.9-beta1 that smooths two rough edges with no API, database, or configuration changes. First, two CSS regressions from the v1.5.9-beta1 settings-UX pass are corrected so the frontend renders as intended. The new (i) field-hint tooltips were nearly unreadable in the Nexus dark theme — it defines `surface-variant` but no `on-surface-variant`, so Vuetify's auto-derived tooltip text came out too muted (reported on the Settings and Telegram hints); every tooltip now gets a solid dark-background/light-text scheme that reads well on both light and dark themes. And `persistent-placeholder` together with an append-inner (i) icon caused Vuetify to constrain the floating field label, clipping short labels to "Add…", "P…", "Do…"; the floating label is now allowed to size to its content instead of being truncated. Both fixes live in unlayered `App.vue` rules, which win over Vuetify's `@layer` CSS. Second, the installer and self-update no longer hang on a stalled mirror: `install.sh` (the tarball and its `.sha256` downloads) and the `s-ui.sh` self-update called `wget` with no timeout, so a single stuck `release-assets.githubusercontent.com` (Fastly) node could block the whole install for roughly 15 minutes before failing; the downloads now pass `--timeout=20 --tries=5 --retry-connrefused`, so a stalled connection is abandoned in 20 seconds and retried against a freshly resolved node.

**RU**

v1.5.9-beta2 — небольшое дополнение к v1.5.9-beta1, сглаживающее две шероховатости без изменений API, базы данных и конфигурации. Во-первых, исправлены две CSS-регрессии из прохода по UX настроек в v1.5.9-beta1, чтобы фронтенд отображался как задумано. Новые (i)-тултипы с подсказками к полям были почти нечитаемы в тёмной теме Nexus: она задаёт `surface-variant`, но не `on-surface-variant`, поэтому авто-выведенный Vuetify цвет текста тултипа получался слишком приглушённым (замечено на подсказках страниц «Настройки» и Telegram); теперь каждый тултип получает плотную схему «тёмный фон / светлый текст», хорошо читаемую и в светлой, и в тёмной теме. А `persistent-placeholder` вместе с (i)-иконкой в append-inner заставлял Vuetify ограничивать ширину плавающей подписи поля, обрезая короткие подписи до «Add…», «P…», «Do…»; теперь плавающая подпись подгоняется под содержимое и не обрезается. Оба исправления — в нелейерных правилах `App.vue`, которые побеждают CSS Vuetify из `@layer`. Во-вторых, установщик и самообновление больше не зависают на застрявшем зеркале: `install.sh` (загрузка tarball и его `.sha256`) и самообновление `s-ui.sh` вызывали `wget` без таймаута, поэтому один зависший узел `release-assets.githubusercontent.com` (Fastly) мог блокировать всю установку около 15 минут перед ошибкой; теперь загрузки используют `--timeout=20 --tries=5 --retry-connrefused`, так что зависшее соединение прерывается за 20 секунд и повторяется с заново разрешённым узлом.
